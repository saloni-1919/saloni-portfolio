# Saloni Cinematic Portfolio V4.4 — Changes

## Work = Projects + GitHub
- Home: featured work and GitHub repository preview are now in the same Work section. Removed the extra full-width GitHub section.
- `/projects`: one destination for selected project case studies plus the searchable complete public repository archive.
- New public GitHub repos continue to appear from the live API, with a build-generated snapshot as fallback.

## Tableau dashboards
- Replaced the continuously moving carousel with an editorial spotlight and selectable thumbnail cards.
- SaaS Customer Churn & Revenue Retention remains first, then Airline Operations and E-Commerce Pricing.
- Keyboard-accessible previous/next buttons, search on full dashboard page, and interactive Tableau modal.
- New public Tableau workbooks remain eligible for automated discovery at scheduled GitHub Pages rebuilds; this is best-effort because Tableau’s profile listing endpoint is unofficial.

## Motion
- GSAP scroll-triggered section/education/career card reveals; existing Framer Motion page reveals retained.
- Subtle hover expansion, rise, soft orange border glow for project cards, repos, awards, education, skills, publication cards, buttons and dashboard thumbnails.
- Reduced-motion preference disables decorative transitions.

## Not changed
- Site colors/typography, current unique project artwork, Saloni’s original photograph, content from resumes, Scholar Award, papers, education, certification placeholder, PDF paths, static hosting workflow.

## Launch
```powershell
npm install
npm run check
npm run dev
# After reviewing:
npm run build
```

The project ZIP has `package.json` directly at its root.
